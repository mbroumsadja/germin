# 🧮 Projet : La calculatrice

**Niveau 1** — Tu vas écrire tes premières fonctions JavaScript.

## Ce que tu dois faire

Ouvre `public/js/script.js`. Chaque fonction est déjà déclarée mais vide : à toi de la compléter.

1. `addition(a, b)` → renvoie la somme de `a` et `b`
2. `soustraction(a, b)` → renvoie `a - b`
3. `multiplication(a, b)` → renvoie le produit
4. `division(a, b)` → renvoie `a / b`, ou `null` si `b` vaut `0`
5. `moyenne(nombres)` → renvoie la moyenne d'un tableau (`0` si le tableau est vide)

## Comment vérifier

```bash
germin test
```

Chaque test réussi fait avancer ta carte dans le Kanban (`germin kanban`).

## Besoin d'aide ?

`germin hint` te donne un indice, de plus en plus précis à chaque demande. Essaie d'abord seul(e) !

## Défi bonus

Ajoute deux champs `<input>` et un bouton dans `index.html` qui utilisent tes fonctions, puis mets ton site en ligne avec `germin deploy`.
