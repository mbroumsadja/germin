# 🙋 Projet : Ma page de présentation

**Niveau 1** — Ta première vraie page web, puis ta première mise en ligne !

## Ce que tu dois faire

Ouvre `index.html` et suis les commentaires `<!-- ... -->` :

1. Un titre principal `<h1>` avec ton prénom
2. Un paragraphe `<p>` qui te présente
3. Une image `<img>` (avec `src` **et** `alt`)
4. Une liste `<ul>` d'au moins 3 passions (`<li>`)
5. Un lien `<a href="...">` vers un site que tu aimes
6. Dans `public/css/style.css` : une couleur de fond pour le `body`

## Comment vérifier

```bash
germin test       # vérifie ton travail
npm install
npm run dev       # voir ta page sur http://localhost:5173
```

## Mettre en ligne

Quand tout est validé : `germin deploy` 🚀
